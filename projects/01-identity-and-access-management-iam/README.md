# Lab 01: Identity and Access Management (IAM) — User Provisioning

## 📌 Executive Summary
This lab simulates end-to-end user account provisioning within an enterprise IT infrastructure. The goal is to enforce security compliance through **Role-Based Access Control (RBAC)** and the **Principle of Least Privilege (PoLP)**, ensuring new employees have the exact level of access required for their roles without compromising network security.

---

## 🎯 Objectives & Scope
* Provision new corporate user accounts with standardized naming conventions.
* Assign users to appropriate **Security Groups** based on department roles.
* Configure initial password requirements and force password change at first logon.
* Verify authorization limits and directory permissions.
