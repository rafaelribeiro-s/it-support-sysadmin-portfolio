# IT Support & System Administration Portfolio

Welcome to my hands-on technical portfolio! This repository showcases a structured progression of practical labs, case studies, and enterprise configurations covering IT Operations, System Administration, Endpoint Security, and Data Governance.

---

## 🧠 Core Competencies & Technologies

* **Identity & Access Management (IAM):** Active Directory, User Provisioning, Role-Based Access Control (RBAC), Least Privilege Principle
* **Endpoint & OS Security:** Group Policy Objects (GPO), Session Timeout Policies, Workstation Hardening, SHA-256 Hash Integrity Verification
* **Hardware & Systems:** Hardware Provisioning, Bottleneck Diagnostics, Component Upgrades, Performance Tuning
* **Storage & Data Management:** Disk Management, CLI Administration (`diskpart`), File Systems (NTFS / exFAT / FAT32)
* **Governance & Continuity:** Enterprise Data Strategy, Backup Policies (3-2-1 Rule), Disaster Recovery (DR)
