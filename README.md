# IT Support & System Administration Portfolio

Welcome to my hands-on technical portfolio.

This repository documents practical labs and case studies focused on **IT Support, System Administration, Identity & Access Management, Endpoint Security, Hardware & Systems, Storage, and Data Governance.**

Each project is designed as a simulated enterprise scenario with documented objectives, technical implementation, validation steps, evidence, and lessons learned.

---

## 🧠 Core Competencies & Technologies

* **Identity & Access Management (IAM):** User Provisioning, Local Identity Management, Role & Privilege Management, Role-Based Access Control (RBAC) Concepts, Least Privilege
* **Endpoint & OS Security:** Windows Security Configuration, Group Policy Objects (GPO), Workstation Hardening, Session Timeout Policies, SHA-256 Integrity Verification
* **Hardware & Systems:** Hardware Provisioning, Bottleneck Diagnostics, Component Upgrades, Performance Tuning
* **Storage & Data Management:** Disk Management, CLI Administration (`diskpart`), File Systems (NTFS / exFAT / FAT32)
* **Governance & Continuity:** Enterprise Data Strategy, Backup Policies, 3-2-1 Backup Strategy, Disaster Recovery (DR)

## 🎯 Portfolio Approach

The projects in this repository follow a progressive approach:

**Provision → Configure → Secure → Validate → Document**

Each lab is presented as a simulated enterprise IT scenario rather than as a collection of isolated technical exercises.

The objective is to demonstrate not only technical execution, but also the ability to translate business requirements into secure and documented IT configurations.
